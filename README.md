# PhysioLearn

تطبيق ويب (PWA) لطلاب العلاج الطبيعي: ملخصات، اختبارات، كتب، حالات سريرية، وقنوات يوتيوب.

- الاستضافة: GitHub Pages (هذا المستودع، الفرع `main`).
- المحتوى والملفات: Supabase (جدول `items` وحاوية `files`)، مع تحديث لحظي لكل المستخدمين.
- الإدارة: افتح الرابط مع `#admin` في آخره وسجّل الدخول بحساب المسؤول. للخروج استخدم `#logout`.
- كل إصدار جديد يُنشر هنا يصل للطلاب تلقائياً عند فتح التطبيق.

## الملفات
- `index.html` — التطبيق
- `config.js` — رابط Supabase والمفتاح العام (anon) وإيميل المسؤول
- `shim.js` — ربط التطبيق بـ Supabase (قراءة، كتابة، تحديث لحظي، رفع ملفات، دخول الإدارة)
- `sw.js` و `manifest.webmanifest` والأيقونات — تثبيت التطبيق على الشاشة الرئيسية
- `seed.sql` — المحتوى الأولي (يُشغَّل مرة واحدة في Supabase)

## حسابات الطلاب (v1.2)
- الطالب ينشئ حساباً من الإعدادات (أيقونة الشخص) ← «تسجيل الدخول / إنشاء حساب». التسجيل اختياري.
- التقدّم (الاختبارات، المحفوظات، آخر ما فُتح) يُحفظ في جدول `progress` ويُستعاد على أي جهاز.
- المسؤول يرى «تقدّم الطلاب» من الإعدادات بعد تسجيل الدخول.
